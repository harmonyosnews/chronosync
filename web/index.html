扫描局域网

扫描当前 IPv4 局域网中的活跃主机，并把主机名和 IP 自动填入设备清单。扫描只探测 TCP 22 和读取 ARP 邻居表，不会尝试登录。

支持逗号分隔多个 IPv4 网段，单次最多 4 个网段 / 1024 个地址。非 SSH 主机需要手动确认后再填写密码，不需要的行可直接删除。
